- The Codex assets are from the installed `com.openai.codex` macOS app bundle.
- The Claude Code assets are from the official Anthropic VS Code extension package. The CLI package itself did not include a separate app icon in the inspected installation.
- The OpenCode assets are directly from `opencode.ai`, including square app icons and light/dark brand previews.
- These files may still be subject to each brand owner's trademark and usage guidelines.
